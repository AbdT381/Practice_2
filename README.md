 Maven Dependency Graph (этапы 1–3)

Инструмент для построения графа зависимостей пакетов менеджера пакетов
**Maven**. Готовые менеджеры пакетов и сторонние библиотеки для получения
зависимостей **не используются** — вся логика парсинга `pom.xml` и обхода
графа реализована вручную.

 Реализованные этапы

- **Этап 1.** CLI-приложение с конфигурацией в TOML, вывод всех параметров
  в формате ключ-значение, обработка ошибок каждого параметра.
- **Этап 2.** Получение прямых зависимостей Java/Maven-пакета по URL
  репозитория (парсинг `pom.xml`), вывод прямых зависимостей.
- **Этап 3.** Построение графа с учётом транзитивности: DFS без рекурсии,
  ограничение глубины, обработка циклов, режим тестирования (локальный
  файл описания графа).

 Описание функций и настроек

 Конфигурационный файл `config.toml`

| Параметр | Тип | Описание |
|---|---|---|
| `package_name` | string | Имя пакета в формате `groupId:artifactId` |
| `repo_url` | string | URL Maven-репозитория **или** путь к файлу тестового графа |
| `repo_mode` | string | `"url"` — реальный репозиторий, `"file"` — тестовый режим |
| `output_image` | string | Имя выходного PNG-файла (используется на этапе 5) |
| `max_depth` | int | Максимальная глубина анализа (1–50) |

 Модули

| Модуль | Назначение |
|---|---|
| `config.py` | Загрузка и валидация TOML-конфигурации |
| `maven_parser.py` | Парсинг `pom.xml`, загрузка тестового графа |
| `graph.py` | Граф зависимостей, DFS без рекурсии, циклы, обратные рёбра |
| `main.py` | CLI-точка входа |

 Сборка и запуск

```bash
'''Требуется Python 3.11+ (tomllib в стандартной библиотеке)'''
make run          ''' запуск с config.toml '''
make run-test     ''' запуск в тестовом режиме'''
make test         ''' pytest '''
make lint         ''' проверка синтаксиса'''
```

 Примеры использования

Реальный репозиторий:

```toml
package_name = "org.apache.commons:commons-lang3"
repo_url = "https://repo1.maven.org/maven2"
repo_mode = "url"
output_image = "graph.png"
max_depth = 2
```

Тестовый режим:

```toml
package_name = "A"
repo_url = "tests/fixtures/simple_graph.txt"
repo_mode = "file"
output_image = "graph_test.png"
max_depth = 3
```

Формат тестового файла (пакеты — большие латинские буквы):

```
A: B C
B: D
C: D E
D:
E: A
```
